## 核心实现逻辑
### 1. Phong 光照模型数学原理Phong 光照模型将物体表面反射光分为环境光、漫反射、镜面高光三部分叠加，最终像素颜色公式：
\(I = I_{ambient} + I_{diffuse} + I_{specular}\)
环境光 (Ambient)：模拟场景多次反射均匀背景光
\(I_{ambient} = K_a \times C_{light} \times C_{object}\)
漫反射 (Diffuse)：遵循 Lambert 定律，强度与光线法线夹角余弦成正比
\(I_{diffuse} = K_d \times \max(0, \mathbf{N} \cdot \mathbf{L}) \times C_{light} \times C_{object}\)
镜面高光 (Specular)：模拟光滑表面定向高光，高光范围由指数 n 控制
\(I_{specular} = K_s \times \max(0, \mathbf{R} \cdot \mathbf{V})^n \times C_{light}\)
\(\mathbf{N}\)为表面法向量，\(\mathbf{L}\)指向光源，\(\mathbf{V}\)指向相机，\(\mathbf{R}\)为反射向量，n为高光指数。
### 2. 隐式几何体与光线求交程序不加载外部模型，依靠光线投射数学公式实现几何体碰撞检测：
红色球体：圆心\((-1.2, -0.2, 0)\)，半径 1.2，固有色\((0.8,0.1,0.1)\)
紫色圆锥：顶点\((1.2,1.2,0)\)，底面\(y=-1.4\)，底面半径 1.2，固有色\((0.6,0.2,0.8)\)
场景配置：相机\((0,0,5)\)，点光源\((2,3,4)\)，白光光源，背景深青色。
### 3. 深度测试（Z-Buffer 遮挡）
屏幕每一个像素发射一条摄像机射线；
分别求解射线与球体、圆锥的相交距离t；
选取最小正数t（离相机最近交点），实现物体遮挡；
使用最近交点坐标计算表面法线，作为着色输入。
### 4. Phong 逐像素着色流程
由交点坐标计算归一化\(\mathbf{L}\)、\(\mathbf{V}\)、反射向量\(\mathbf{R}\)；
分别计算环境光、漫反射、镜面高光三色分量；
三分量叠加后将颜色约束在\([0,1]\)区间；
GPU 并行内核批量完成全部像素渲染。
### 5. UI 交互参数面板滑动条实时调节材质光照参数，参数范围与默认值：
Ka 环境光系数：0.0 ~ 1.0，默认 0.2
Kd 漫反射系数：0.0 ~ 1.0，默认 0.7
Ks 镜面高光系数：0.0 ~ 1.0，默认 0.5
Shininess 高光指数：1.0 ~ 128.0，默认 32.0
